Changelog

What's new in QAdesk. The current release is v0.9.4.

v0.9.4
Current release
  • New Next → button and n/↓ keyboard navigation to step through QA issues; ignoring an issue now advances to the next one automatically.
  • New Editing fonts — per-side font & size for source and target text (e.g. a larger Nirmala UI for Devanagari targets).
  • Improved Smarter false-positive handling: annotation tags, tag-only segments, URLs/emails, and company/legal-entity names are no longer wrongly flagged as untranslated or as tag mismatches.
  • Improved Spelling ignores names carried verbatim from the source; bracket/quote checks compare against the source so cross-segment splits and apostrophes aren't flagged.
  • Fixed Company names and copyright lines left in the source language are surfaced as a warning, not a major error.
Earlier history coming soon. Detailed notes for prior versions are being compiled and will be added here.
